# Esa Personal Portfolio — Next.js Starter

A colorful, premium, responsive personal portfolio starter with a Next.js frontend and a backend contact API route.

## Run locally

1. Install Node.js 18+.
2. In this folder run `npm install`.
3. Run `npm run dev`.
4. Open `http://localhost:3000`.

## Backend

The contact form posts to `/api/contact`. It currently validates and logs the message on the server. For production, connect it to an email provider such as Resend or a database such as Supabase.

## Publish

The project is structured for Vercel/Next.js deployment. Push the folder to GitHub, import the repository into Vercel, and deploy. No separate frontend/backend hosting is required for this architecture because the API route runs as a server function.
